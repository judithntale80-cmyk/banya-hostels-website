# Banya Hostels Website

A PHP and MySQL website for Banya Hostels. The project provides public accommodation information, room enquiry and booking workflows, booking tracking, news/blog content, a gallery, and an administration area.

> **Project context:** BIT 2103 – Internet Technologies & Advanced Website Development.  
> **Technology:** PHP, MySQL, HTML, CSS, JavaScript and Bootstrap.

## Main features

### Public website
- Homepage and information about Banya Hostels.
- Hostel pages with room and facility information.
- Photo gallery.
- News and blog listing and individual article pages.
- Accommodation enquiries and contact information.
- Room booking request form.
- Booking-status tracking.
- XML sitemap generated by `sitemap.php`, exposed as `/sitemap.xml` through Apache rewriting.

### Administration
- Administrator login and logout.
- Hostel and room management.
- Booking management.
- Enquiry management.
- Gallery management.
- Posts management
- Website settings.

### Booking workflow
1. A student selects an available hostel, room and occupancy option.
2. The student submits their contact and intended-stay details.
3. A booking request is created with a pending status.
4. An administrator reviews and approves or rejects the request.
5. Students can use their booking reference and phone number to check its status.

A submitted request should not be treated as an approved reservation until the administrator approves it.

## Technology and architecture

- **PHP:** Server-side page rendering and application logic.
- **MySQL:** Persistent storage for users, hostels, pricing, rooms, bookings, enquiries, gallery items, posts, settings and login-attempt records.
- **PDO:** Database access. The application configuration sets exception error handling and disables emulated prepared statements.
- **HTML/CSS/JavaScript:** Front-end structure, presentation and interactions.
- **Bootstrap:** Responsive layout and interface components.
- **Apache `.htaccess`:** URL rewriting, directory listing protection, selected security headers, caching rules and compression rules (where the required Apache modules are enabled).

## Local setup (WAMP)

1. Install and start WAMP with Apache and MySQL running.
2. Copy the project folder into the WAMP web root, for example `C:\wamp64\www\banya`.
3. Enable Apache's `rewrite_module` because the `.htaccess` file uses URL rewriting.
4. Open phpMyAdmin and create a database named `banya_hostels` (or use the database name configured in `config.php`).
5. Import `schema.sql` into the new database.
6. Open `config.php` and set `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`, `BASE_URL` and `SITE_URL` for your local environment.
7. Visit `http://localhost/banya/` (adjust the URL if your folder name differs).
8. Test the public pages, booking flow, booking tracking and administrator functions.

**Database warning:** `schema.sql` is intended for a fresh installation. Back up an existing database before importing it; importing a fresh-install schema into an existing production database can cause data loss or conflicts.

## Configuration and deployment

Before deployment:
- Use the database name, username and password supplied by the hosting provider.
- Set `BASE_URL` to the correct path for the deployment (often an empty string when installed at the domain root).
- Set `SITE_URL` to the real canonical HTTPS website address.
- Do not commit real production passwords, API keys, private credentials, payment details or personal customer data.
- Enable HTTPS at the hosting provider and carefully enable the HTTPS redirect in `.htaccess` only after the SSL certificate is working.
- Confirm that Apache supports the modules used by `.htaccess` (`mod_rewrite`, `mod_headers`, `mod_expires` and `mod_deflate`) or ask the hosting provider.
- Protect the `admin/` area with authentication and authorization. `robots.txt` is not a security control.
- Review upload permissions and ensure uploaded files cannot execute as scripts.
- Take a database and file backup before deployment or schema changes.

## SEO and performance notes

- Shared page metadata is generated in `includes/header.php` using page-specific `$title` and `$desc` values and site settings.
- Friendly hostel and news URLs are rewritten by `.htaccess`.
- `sitemap.php` generates the XML sitemap; `.htaccess` maps `/sitemap.xml` to that script.
- `robots.txt` contains crawler instructions and the sitemap location. Update its sitemap URL to the real production domain before launch.
- The current `.htaccess` includes basic expiration rules for JPEG/PNG images, CSS and JavaScript, plus DEFLATE compression rules for selected text resources. These rules depend on server module support.
- The shared stylesheet URL uses a `filemtime()` version query to help browsers fetch updated CSS after a file change.

Run PageSpeed Insights or GTmetrix before and after optimization and keep dated screenshots. Do not claim a performance improvement unless it is supported by the recorded test results.

## Privacy and security

Do not add live database credentials, administrator passwords, booking records, payment receipts or other personal/client data to a public repository. Keep only source code, safe sample configuration, schema definitions and documentation in GitHub. Replace any exposed credential immediately and remove it from repository history where necessary.
